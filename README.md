World in One Day draws a newspaper front page summarizing the world news of Tuesday 24 November 2026 as a single 1024 x 1024 PNG: a US jury convicts Huawei, tankers ablaze in the Strait of Hormuz, Ukraine's drones hit Russian ships, Nvidia reinstates its CEO, 14 nations back the ICJ Rohingya ruling, a Turkish helicopter crash, hostages in Cartagena, the UN chief's call for AI rules, and Senegal restored as Africa's champions. It uses only the Python 3.13 standard library — the PNG encoder and the type are hand-rolled in main.py.

News sources checked on 25 November 2026: Reuters, AP, France 24, The Guardian, IRNA, UKMTO, Tasnim, Daily Summary Of, Principia.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is `out/entry.png`.
